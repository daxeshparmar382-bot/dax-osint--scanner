# DAX OSINT SCANNER

A privacy-focused Android dashboard built with **Kotlin** and **Jetpack Compose**.

## Features

- Public username destination search across supported platforms
- Public website DNS resolution and HTTPS reachability lookup
- Interactive privacy checklist
- Local scan history stored on-device
- Premium dark navy and purple Material 3 interface

## Build

Open the project in Android Studio, allow Gradle to sync, and run it on an Android device or emulator.

```bash
./gradlew assembleDebug
```

## Important

This app is a public-information utility. It generates links to public profiles and performs basic domain/DNS reachability checks. It does not bypass privacy controls, access private accounts, or claim to reveal protected personal data. Use only lawfully and with authorization.
